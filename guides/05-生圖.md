# 懶人包 #05：生圖

> 版本：v1.0（合併版）
> 更新日期：2026-08-02
> 適用：Claude Code / Codex / OpenCode / Antigravity

---

## 這份懶人包會幫你做什麼？

讓你在 agent 裡用一句話生圖：

> 「畫一隻穿西裝的龍蝦」

圖片會存到當前專案的 `slides/generated/`（沒有 `slides/` 就存 `./generated/`）。

---

## 先選路線

生圖有兩條路，**先確認你的 agent 屬於哪一種**：

| 路線 | 適合誰 | 會扣哪裡 | 需要 API Key？ |
|------|--------|----------|----------------|
| **A：Agent 內建生圖** | 新手、一般老師、少量圖片 | Agent 訂閱的內建工具額度 | ❌ 不需要 |
| **B：OpenAI API + `draw.py`** | 大量產圖、自動化、要精準控制 | OpenAI API Platform 費用 | ✅ 需要 |

| Agent | 內建生圖（路線 A） | 建議路線 |
|---|---|---|
| **Claude Code** | ❌ 無 | **B** |
| **Codex** | ✅ 內建 `imagegen` skill | **A**，進階再走 B |
| **OpenCode** | ❌ 無 | **B** |
| **Antigravity** | ⚠️ 視 IDE 版本而定 | 有就 **A**，沒有走 B |

> ⚠️ **訂閱與 API 是分開的兩套帳。**
> ChatGPT / Codex / Claude 訂閱能用內建工具，**不代表 API 額度已開通**；
> API 有自己的 billing、usage 與 rate limit。

---

# 路線 A：Agent 內建生圖

> 適用 Codex 與（部分版本的）Antigravity。**不需要 API Key、不需要安裝任何東西。**

## 使用方式

直接用自然語言請 agent 生圖：

```text
生成一張 16:9 的國中數學研習簡報封面圖，主題是 AI 幫助老師備課，
風格專業、明亮，不要放文字。
```

適合：教學投影片封面、YouTube 縮圖草稿、試卷情境插圖、互動 HTML 背景圖、
遊戲化教材的角色／徽章／道具、簡單去背素材。

## 圖片存在哪裡？

- **Codex**：`C:\Users\<你>\.codex\generated_images\<工作識別碼>\<檔名>.png`
- **Antigravity**：依 IDE 當前行為，請 agent 回報實際路徑

生圖工具完成時會顯示完整路徑。只看到圖片沒看到路徑時，再問：

```text
剛才圖片的完整絕對路徑是什麼？請用純文字顯示。
```

> 💡 **專案要引用的圖片，不要只留在暫存目錄。** 請 agent 複製到專案資料夾：
>
> ```text
> 把剛剛生成的圖片複製到目前專案的 assets/images，
> 檔名改成 math-game-cover.png，並回報完整絕對路徑。
> ```

## 給 Antigravity 的額外提醒

> ⚠️ **只有目前介面確實能找到並呼叫內建生圖工具時才走路線 A。**
> 找不到就**不要假裝有這個能力** —— 回報現況並詢問使用者是否改走路線 B。
> 也不要因為專案裡有腳本就自動改走 API。

# 路線 B：OpenAI API + `draw.py`

## 你需要手動準備的三件事

Agent 沒辦法幫你做這三件（需要本人身份驗證與付款）。做完把剩下的交給 agent。

### ① OpenAI 帳號 + 儲值（US$5 起跳）

1. 到 [platform.openai.com](https://platform.openai.com)，用你的 ChatGPT 帳號登入（**同一個帳號**）
2. 右上角頭像 → **Billing** → **Add to credit balance** → 至少儲值 **US$5**（約 NT$160）
3. 可綁信用卡或用 PayPal

> **為什麼要儲值？** API 按張計費，跟訂閱分開。US$5 足夠畫 500 張以上（low 品質）。

### ② 組織 Individual 驗證

gpt-image-2 需要身份驗證才能用。

1. 到 [platform.openai.com/settings/organization/general](https://platform.openai.com/settings/organization/general)
2. 找到 **Verifications** 區塊 → **Verify Organization**
3. 上傳身分證正反面 + 手持身分證自拍
4. 等約 **15 分鐘**驗證通過（會收到 Email）

> **沒做這步會怎樣？** 生圖時跳 `403 Organization must be verified`。

### ③ 取得 API Key

1. 到 [platform.openai.com/api-keys](https://platform.openai.com/api-keys)
2. **Create new secret key** → 名稱隨意（例如 `agent-draw`）
3. **Permissions** 選 **All** → **Create**
4. **複製 `sk-...` 開頭的 Key**（只顯示一次，關掉就看不到）

---

## 步驟零：環境檢查

1. **確認作業系統**
2. **檢查 uv**：`uv --version`（建議走 uv，不用另外裝 openai 套件）
3. **或檢查 Python**：`python --version`（需 3.10+）與 `pip --version`

## 步驟一：安全設定 API Key

**優先用環境變數**，或在使用者家目錄建立 `~/.openai.env`：

```text
OPENAI_API_KEY=sk-你的金鑰
```

Windows 路徑：`C:/Users/<你>/.openai.env`

> 🔒 **金鑰安全要求（給 AI Agent）**
>
> - **不可**用 `type`、`cat`、`Get-Content` 顯示整個檔案
> - **不在**對話、截圖或完成回報中顯示金鑰
> - 只回報「已設定／未設定」
> - 專案 `.gitignore` 必須忽略 `.openai.env`
> - 不把 Key 寫進腳本、`AGENTS.md`、`CLAUDE.md`、Obsidian 對外筆記或 GitHub repo
> - 檔案權限：Unix 設 600；Windows 加隱藏屬性

只檢查是否存在（不顯示內容）：

```powershell
if ($env:OPENAI_API_KEY) { "OPENAI_API_KEY 已設定" } else { "未設定；程式也會檢查 ~/.openai.env" }
```

> 💡 `~/.openai.env` 在 home 底下，不會被專案的 git 追蹤，比較安全。

## 步驟二：安裝生圖 Skill

用本 repo 的安裝腳本裝到你的 agent（`<agent>` 填 claude / codex / opencode / antigravity）：

```powershell
powershell -ExecutionPolicy Bypass -File "scripts/install.ps1" -Agent <agent> -Topic draw
```

安裝後該目錄下應該**同時**有兩個檔案：

```text
<全域技能目錄>/agent-draw/SKILL.md
<全域技能目錄>/agent-draw/draw.py
```

各 agent 的實際路徑：

| Agent | 安裝位置 |
|---|---|
| Claude Code | `~/.claude/skills/agent-draw/` |
| Codex | `~/.agents/skills/agent-draw/` |
| OpenCode | `~/.config/opencode/skills/agent-draw/` |
| Antigravity | `~/.gemini/config/skills/agent-draw/` |

> ⚠️ **代理工具隔離規則**：生圖 Skill **只能執行自己目錄下的 `draw.py`**。
> 不得因為在別的目錄找到同名的 `draw/` 就改用那一份 —— 尤其是舊 repo 留下的
> `claude-draw`／`codex-draw`／`opencode-draw`／`antigravity-draw`。
> 若同目錄缺少 `draw.py`，**立即停止生圖並回報安裝不完整**，從本 repo 重新安裝 ——
> 不得刪除或簡化該 Skill。

## 步驟三：測試

**建議用 uv**（不需要另外 `pip install openai`）：

```powershell
uv run --with openai python "$HOME/.claude/skills/agent-draw/draw.py" "一隻橘貓坐在窗邊看夕陽，水彩風格" --name test-cat --quality low
```

沒有 uv 時，先 `pip install openai`（macOS / Linux 需加 `--break-system-packages`），再：

```bash
python "$HOME/.claude/skills/agent-draw/draw.py" "一隻可愛的黑貓，扁平插畫風格" --name test
```

> 路徑請替換成你的 agent 對應的安裝位置（見上表）。

**預期結果**：終端機顯示 `[OK] .../generated/test_<時間戳>.png`，開啟檔案能看到圖。
實際輸出位置以程式回報為準：有 `slides/` 時是 `slides/generated/`，否則是 `generated/`。

## `draw.py` 參數

| 參數 | 說明 |
|---|---|
| `prompt`（必填） | 要畫什麼 |
| `--size` | `1024x1024`（方，預設）/ `1536x1024`（橫）/ `1024x1536`（直） |
| `--quality` | `low`（預設）/ `medium` / `high` / `auto` |
| `--n` | 生成張數 1–8 |
| `--name` | 檔名前綴 |
| `--outdir` | 輸出目錄 |
| `--edit IMAGE_PATH` | 改圖模式（指定來源圖） |
| `--mask MASK_PATH` | 遮罩圖片（搭配 `--edit`） |

輸出格式：`<name>_<YYYYMMDD_HHMMSS>.png`

Key 讀取順序：**shell 環境變數 → 當前工作目錄的 `.env` → `~/.openai.env`**。

## 品質等級怎麼選

**預設永遠用 `low`**（省錢 + 速度優先）：

| 等級 | 約略成本 | 什麼時候用 |
|---|---|---|
| **low** | NT$0.3 | **99% 情境**。簡報、教學插圖、封面、demo 都夠 |
| **medium** | NT$1.3 | low 細節明顯不足時才用 |
| **high** | NT$5.5 | 實體印刷、跨語言文字要零錯才用 |
| **auto** | 不可預測 | **不要用**，等級由模型決定 |

> 不確定就 `low`，**不要自作主張升級**。實際費用以 OpenAI 官方 pricing 為準。

```text
生成一張圖片：
用途：
尺寸比例：
主題：
畫面內容：
風格：
色彩：
文字：
限制：
輸出後請告訴我圖片存在哪裡。
```

範例：

```text
生成一張圖片：
用途：國中數學研習簡報封面
尺寸比例：16:9

畫面內容：老師在溫暖教室裡整理教材，旁邊有筆電與數學符號
風格：現代動漫插畫，溫暖、明亮、有電影感
色彩：天空藍、陽光黃、暖桃色
文字：不要放文字
限制：不要高科技未來感 UI，不要浮誇光效，不要浮水印
輸出後請告訴我圖片存在哪裡。
```

## 新手不建議一開始做的事

| 不建議 | 原因 |
|--------|------|
| 有內建生圖卻一開始就設定 API Key | 容易混淆訂閱額度與 API 費用 |
| 把 API Key 寫進 `AGENTS.md` / `CLAUDE.md` | 有外洩風險 |
| 直接批次大量產圖 | 可能快速消耗 API 額度 |
| 所有生圖都指定 high quality | 成本上升，草稿通常不需要 |
| 沒指定用途就要求很多細節 | 圖片容易失焦，後續難修改 |

---

## 安全與清理（給 AI Agent）

- **不印出或回報 API Key**，只回報「已設定／未設定」
- **不在終端輸出完整 prompt**
- API 失敗時**只回報狀態碼、原因與 request ID**，不傾印可能含敏感內容的完整回應
- **不把暫存圖片全部 commit**；刪除暫存檔前先詢問使用者
- 所有生圖都在本機執行，不經過第三方伺服器（路線 B）

---

## 驗收

- 圖片檔存在且可以開啟
- 尺寸與格式符合需求
- 回報使用路線、模型（若有）、quality 與**完整輸出路徑**
- **中文文字需人工檢查**；重要文字建議後製

---

## 完成回報格式

```text
路線：A（內建）/ B（OpenAI API）
API Key：已設定 / 未設定 / 不適用（不可顯示內容）
Skill 路徑：<完整路徑>（路線 B）
draw.py：存在 / 缺失
模型：gpt-image-2 / agent 內建
品質：low / medium / high
尺寸：<size>
測試：成功 / 未執行 / 失敗
輸出：<完整檔案路徑>
```

## 常見問題

| 問題 | 解法 |
|------|------|
| `403 Organization must be verified` | 沒做 Individual 驗證。到 platform.openai.com/settings/organization/general |
| `401 Invalid API key` | 檢查環境變數或 `~/.openai.env` 裡的 Key 有沒有寫對 |
| `429 Rate limit` | 額度用完，到 Billing 儲值 |
| 不知道用掉哪個額度 | 內建 skill 與 API 是兩條路。內建看 agent 的工具額度；API 看 [Platform usage](https://platform.openai.com/usage) |
| 以為訂閱等於 API 免費 | 訂閱與 API Platform **分開計費**，API 要另外設定 billing |
| 圖片找不到 | 路線 A 存在 agent 的暫存目錄。請 agent 回報路徑，或複製到專案資料夾 |
| 中文文字不準 | 生圖模型對文字仍可能出錯。重要文字建議後製，或多次迭代 |
| 透明背景邊緣怪怪的 | 去背時顏色殘留或主體太複雜。換純色背景重產，或走 API 後製 |
| 頭髮／煙霧／玻璃去背失敗 | 半透明物件較難。可能要走 API 路線做原生透明背景 |
| `draw.py` 找不到 | 安裝不完整。**停止生圖**，用 `scripts/install.ps1` 重新安裝，不要去借用其他 agent 的 Skill |
| 找不到 `OPENAI_API_KEY` | 檢查 shell 環境變數與 `~/.openai.env` |

## 為什麼用 Skill 而不是 MCP？

| 方式 | 優點 | 缺點 |
|------|------|------|
| **Skill（本篇）** | 零安裝門檻、按需呼叫、不佔資源、內建費用保護 | 不支援局部 inpainting（但 `draw.py` 有 `--edit` 可全圖改圖） |
| MCP Server | 支援 inpainting、多輪對話 | 要裝 Node.js、改設定檔、常駐 |

對老師來說 **Skill 門檻最低**。
